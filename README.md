# 局域打印站 LanPrint

支持 Windows、macOS、Linux 的办公室共享打印与扫描工具。公用电脑连接设备并运行 LanPrint，同事在浏览器打开内网地址即可使用。

| 主机系统 | 构建架构 | 打印 / PDF / 扫描 |
| --- | --- | --- |
| Windows 10/11 | x64 | GDI / WinRT PDF / WIA |
| macOS | Intel x64、Apple Silicon ARM64 | CUPS / Poppler / SANE |
| Linux | x64、ARM64 | CUPS / Poppler / SANE |

macOS、Linux 的安装、依赖、启动命令与功能差异见[跨平台部署说明](docs/CROSS-PLATFORM.md)。扫描需设备有对应平台的 WIA/SANE 驱动；macOS 的 Image Capture 专用设备尚不支持。

## 下载与 GitHub 自动构建

[GitHub Actions](https://github.com/sck03/Lan-printing/actions) 中分别提供 `Build Windows`、`Build macOS`、`Build Linux` 三份工作流。推送到 `main`、提交 PR、推送 `v*` 标签或点击 **Run workflow** 都可触发。在成功运行的 **Artifacts** 中下载相应 ZIP / tar.gz，包内含可执行文件、文档和 SHA256 校验值；这些包不会自动发布为 GitHub Release。

源码和构建产物均不包含注册码生成器、签发私钥或已签发注册码。应用仅内嵌 `assets/license-public-key.hex` 验证公钥；已有注册码规则保留。

## Windows 使用

1. 在公用电脑上安装打印机/扫描仪的 Windows 驱动，确认 Windows 可以正常打印、WIA 可以扫描。
2. 双击 `dist/LanPrint.exe`，程序进入系统托盘并打开浏览器。首次运行需在主机复制机器码，向软件提供方获取注册码，注册成功后才能打印和扫描；以后重启自动验证。
3. Windows 防火墙询问时允许程序访问**专用网络**。同事打开网页上显示的地址，例如 `http://192.168.1.10:17860`。有多个网卡时使用同事可访问的主机 IPv4 地址。
4. 打印：上传 PDF/图片 → 查看预览 → 选择打印参数 → 提交。扫描：放置原稿 → 选择扫描设置 → 扫描 → 在“我的任务”下载。
5. 程序文件与托盘使用绿色打印机图标。右键托盘图标可以打开网页、查看共享地址、创建桌面快捷方式、打开数据目录、切换“开机启动”、临时阻止自动睡眠、打开 Windows 打印机/启动应用设置或退出。开机启动显示当前开关状态，默认关闭，在当前用户登录后生效。主机需保持开机，程序保持运行。
6. 选择“创建桌面快捷方式”后，可从桌面启动打印站；程序已运行时会打开网页。快捷方式保留当前数据目录、端口和演示模式，创建后请勿移动 EXE。
7. 主机网页顶部新增“局域网访问检查”，自动检查当前 TCP 端口和 Windows 防火墙，也可从托盘“检查与修复局域网访问”打开。缺少有效规则时点击“一键修复端口放行”，在主机确认 Windows 管理员授权后自动复查。其他电脑不能执行修复。

发行 EXE 内嵌网页，不要求安装 Rust、Python、Node、.NET、WebView2 或 PDF 阅读器。Windows 系统组件和设备驱动仍然必需。浏览器客户端可以是 Windows、macOS、Linux 或手机。

## 首版功能和范围

- 离线注册码、本机绑定、永久授权；未注册时仅显示注册页面，后端接口与设备执行进程均校验。注册码向软件提供方申请，见[注册码说明](docs/LICENSING.md)。同事使用已注册的主机不需要再次注册。
- PDF、PNG、JPEG、BMP，以及 DOC/DOCX、XLS/XLSX、PPT/PPTX 上传；安装兼容 WPS 时还可处理 WPS/ET/DPS。办公文档由主机 Office/WPS 转成 PDF 后，使用同一套预览和打印流程。默认单文件上限 50 MB、最多 1000 页。
- 打印机选择、1–99 份、页码范围、A4/A5/Letter、横纵向、彩色/黑白、设备支持时自动双面。新增完整驱动预设，可保留照片纸类型、原厂质量、高速/双向打印、无边距等驱动选项。通用模式仍使用网页参数；选择预设时纸张、方向、色彩和双面均以预设为准。
- 图像处理可选 300/600 DPI，按实际打印区域计算，长边最多 7016 像素。照片建议 600 DPI；它与原厂驱动的质量/高速设置独立，不能恢复低分辨率原图的细节。
- WIA 平板/自动进纸器扫描，100/200/300 DPI、彩色/灰度、PDF/JPG/PNG 下载。**每个任务只扫描一页**；ADF 也只取一页。多页合并、ADF 批量和 TWAIN-only 扫描仪尚未支持。
- 后台串行任务队列、等待中任务可取消。驱动操作在子进程执行并设置超时，网页服务不等待驱动线程。已提交的打印需在主机 Windows 打印队列取消。
- 任务持久化；服务重启时将未结束任务标记中断，**不会自动重印**。网页“已提交打印机”表示进入 Windows 队列，并不保证已经出纸。超时/中断后先检查主机队列和打印机，再决定是否重试。
- 浏览器签名会话、CSRF 校验、只允许内网客户端和内网 Host。不同浏览器默认只能查看自己的文件和任务；清除 Cookie 后无法找回原会话文件。主机管理员仍能读取数据目录。
- 文件无操作 30 分钟后清理；预览/下载延长保留时间，排队中的文件不会清理。任务记录保留 24 小时。默认暂存文件配额 1 GB，最多 1000 个文件（含扫描结果），活动队列最多 50 个。
- Office/WPS 转换需要主机安装并初始化兼容办公软件；客户端无需安装。转换串行执行，120 秒超时，禁用自动化宏，使用独立进程；无法隔离时会拒绝转换。DOCM/XLSM/PPTM 不接收。表格沿用文档保存的打印区域与分页；转换后只保留 PDF，删除上传的办公原文件。默认隐藏会弹出保存窗口的常见虚拟打印机。

仅用于可信办公室内网，传输为 HTTP，浏览器会话隔离不等同于员工身份认证。不要端口映射到公网；有敏感资料或不可信访客的网络应由管理员隔离接入。

## 局域网端口检查与修复

请在运行打印站的电脑打开 `http://127.0.0.1:17860`（自定义端口以实际配置为准）。检查会显示监听端口、主机地址、当前网络类型以及防火墙状态；检查失败时可以重新检查。

修复只为当前 EXE 和当前 TCP 端口创建或更新入站允许规则，远程地址限制为 `LocalSubnet`（与主机直连的本地子网），适用于域、专用和公用网络。不会关闭或开启防火墙，不修改网络类型，不删除现有阻止规则，也不设置路由器端口映射。取消管理员授权时不会修改设置。规则按 EXE 路径和端口区分，移动程序或更换端口后需重新检查。

如果存在阻止规则、“阻止所有传入连接”或企业策略限制，界面会提示需要主机管理员处理，不会误报已修复；防火墙关闭时会如实显示，也可提前配置放行规则。自定义地址、接口或身份限定的规则无法确认覆盖全部本地子网时，会提示未确认放行。本机检查不能证明其他电脑一定能访问：第三方防火墙、无线客户端隔离、跨网段路由仍需从另一台电脑打开共享地址验证。演示模式不检查或修改真实防火墙。

## EPSON L300 照片打印

1. 在运行打印站的主机打开 `http://127.0.0.1:17860`，选择 EPSON L300。
2. 在“驱动打印预设”下填写名称，例如“照片纸 · 高质量 · 关闭高速”，点击“打开原厂设置并保存预设”。
3. 在 EPSON 原厂窗口选择实际照片纸类型、纸张尺寸、质量“高”和“彩色”；在“更多选项 → 另外的设置”取消“高速”。点击“确定”保存（不会修改 Windows 全局默认值）。
4. 选用保存的预设，图像处理清晰度选择“600 DPI · 高清照片”，核对预览后提交。其他电脑点击“刷新预设”即可选用；创建和删除只能从主机回环地址操作。

预设绑定打印机和驱动版本，保存完整 DEVMODE（包括厂商私有参数）。驱动升级后如提示不兼容，重新创建预设。最多 50 个预设，正在被任务使用的预设不能删除。打印照片仍按比例适配打印区域；原厂“无边距”等效果以驱动能力为准。

文件不是打印完成后立即删除：默认 30 分钟无操作后由每分钟运行的清理任务删除；预览/下载续期，排队或打印中保护文件。任务记录保留 24 小时。网页中的文件列表自动刷新不会延长文件寿命。

## 配置

首次运行生成 `%LOCALAPPDATA%\LanPrint\config.json`，退出程序后编辑并重新启动。不要公开其中的 `secret`。托盘菜单可以打开此目录。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `port` | 17860 | 网页端口 |
| `retention_minutes` | 30 | 文件无操作保留时间 |
| `max_upload_mb` | 50 | 单文件大小限制 |
| `max_storage_mb` | 1024 | 已入库文件总配额；处理中临时文件额外占用空间 |
| `max_pending` | 50 | 活动任务上限 |
| `show_virtual_printers` | false | 是否显示常见虚拟打印机；可能要求主机端交互 |

命令行：`LanPrint.exe [--port 17860] [--data-dir PATH] [--no-tray] [--background] [--demo]`。

`--background` 保留托盘但不自动打开浏览器。登录自动启动默认关闭，在托盘中开启；它在当前用户登录 Windows 后启动，不是无人登录的系统服务。防自动睡眠开关只在本次运行生效，退出后恢复。

显卡不限定 AMD：Intel 核显、AMD 核显、NVIDIA 等使用相同 Windows 接口，不需 CUDA 或厂商 SDK。当前实测主机为 AMD RX 580；其他显卡尚需实机验收，系统 PDF 渲染受 Windows/驱动影响，没有强制 CPU 渲染开关。详见兼容说明。

## 编译与测试

开发环境需要 Rust stable、Windows 链接工具及资源编译器（GNU 使用 windres，MSVC 使用 Windows SDK 的 rc.exe）。默认构建目标使用当前 Rust 工具链；支持 `x86_64-pc-windows-gnu` 和 `x86_64-pc-windows-msvc`，MSVC 已配置静态 CRT。多尺寸图标已提交到 assets，可用 `scripts/generate-icon.ps1` 重新生成。在 Windows 上执行：

```powershell
./scripts/build.ps1 -OutputDirectory dist/windows-new
```

或 `cargo test --locked`、`cargo build --release --locked --bin lan-print`。macOS / Linux 安装主机依赖后运行 `bash scripts/build-unix.sh <Rust目标> dist/new-build`。打包目录须为尚未存在的新目录。测试涉及页码校验、会话签名、网络限制、文件隔离、任务幂等、重启恢复和原生 PDF 打开/渲染，不消耗纸张。

跨平台启动验证：`python scripts/host-smoke.py <可执行文件路径>`，无需私钥或真实设备。内部 Windows 浏览器集成测试：`node scripts/smoke.cjs`，需要私有签发工具、开发机 Playwright 和 Edge；公开仓库 CI 不依赖这些私有文件。真实设备兼容性仍需在办公室连接的打印机与扫描仪上验证。

## 技术选择与参考

本项目采用 Rust + Axum + 内嵌原生 HTML/CSS/JS；Windows `windows` crate 调用 WinRT PDF、GDI 打印、WIA COM 和系统托盘。macOS / Linux 使用独立进程调用 CUPS、Poppler、SANE 和可选的 LibreOffice。不需要前端构建。

Go 同样可以交付免安装 EXE，HTTP 服务维护成本较低；本项目选择 Rust 主要因为 Windows COM/WinRT 的类型化接口覆盖，且易于把打印、扫描和 PDF 能力集成到同一个原生程序。C# 自包含也可免安装，但需携带 .NET 运行时；C/C++ 可实现相同部署方式，内存与资源管理需要更多维护。

功能参考：

- [a937750307/lan-printing](https://github.com/a937750307/lan-printing)，参考 2.6 分支：扫描、托盘、浏览器入口。
- [cczyx/intranet-printing](https://gitee.com/cczyx/intranet-printing)：预览、后台队列和打印参数设置。

实现重新编写，没有复制这两个 Python 项目的源代码。第三方 Rust 依赖的版本锁定在 `Cargo.lock`，其授权以各依赖的许可证为准。
