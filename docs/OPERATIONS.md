# 部署、升级与故障处理

## 首次部署

1. 将 `LanPrint.exe` 放到固定的本地可写位置，例如 `C:\Tools\LanPrint`。运行主机为 Windows 10/11 x64，安装设备厂商打印和 WIA 扫描驱动。
2. 双击程序，确认网页能列出设备，先用 Windows 自带程序验证设备，再在打印站实际打印/扫描一页验收。
3. 防火墙仅允许专用网络；给办公室主机设置 DHCP 地址保留，将网页的内网地址交给同事。多网卡主机用实际可达 IPv4；网页自动检测地址不保证适用于所有 VPN/虚拟网卡。
4. 右键托盘选择“开机启动（当前用户登录后）”。已勾选表示启动项存在；如果 Windows 设置/任务管理器禁用启动应用，还需在那里启用。
5. 按需勾选“本次运行阻止自动睡眠”。长期使用时由管理员配置合适的电源计划。

自启动在该用户登录 Windows 后生效，可在锁屏状态继续服务；注销用户会结束应用。开机停留登录界面、休眠、关机时不可用。自动启动不弹浏览器；托盘双击可打开。它不是开机前登录的 Windows 服务，不需要管理员权限，不会自动更改系统登录方式。开关只影响当前数据目录对应的启动项。

改动 EXE 位置前先在旧位置关闭启动项，再在新位置打开。改动数据目录时同样先关闭旧目录的启动项。只替换同一路径 EXE 无需重新启用；通过命令行改变 `--port` 的实例需重新关闭/开启以更新启动命令。Run 命令超过 260 个 UTF-16 字符时拒绝启用，请缩短路径。

## 升级与回滚

1. 通知同事暂停提交，等待任务结束，并检查 Windows 打印队列。不要在运行中覆盖 EXE。
2. 托盘退出；确认该数据目录的主进程和子进程结束。
3. 备份旧 EXE 和完整数据目录（含密钥、状态和文件），保持备份受主机访问权限保护。自动启动注册不在备份 JSON 中。
4. 阅读新版本的数据格式说明。当前 0.1.0 没有自动迁移框架；未来若格式改变，发布者须提供迁移与回滚工具。
5. 保持路径不变替换 EXE，运行检测脚本、浏览器演示测试和一页实际打印扫描。刷新客户端网页以加载新版内嵌前端。
6. 失败则停止新版，恢复旧 EXE 和升级前整份数据。恢复时活动任务仍会标为中断；检查 Windows 队列后由用户决定重新提交，避免重复出纸。恢复旧备份会丢弃升级后新增记录，需先另存这些资料。

## 兼容性检测

发行包自带 PowerShell 检测脚本，不需安装开发运行时。在发行目录执行：

```powershell
& "$env:WINDIR\System32\WindowsPowerShell\v1.0\powershell.exe" -NoProfile -ExecutionPolicy Bypass -File .\scripts\check-compatibility.ps1 -Exe .\LanPrint.exe
```

它生成演示 PDF、检查页数、渲染预览并枚举设备，记录 Windows/显卡驱动版本、EXE SHA256、结果与设备警告。输出在独立临时目录；不修改启动项、不启动网页、不使用真实扫描仪或提交打印。脚本通过不代表扫描设备可用：同时检查 `report.json` 的 `devices.warnings` 和设备列表，并目视检查 `preview.jpg`。报告含设备名称，分享前可自行删除这些名称。无需分享真实文档或 `config.json`。

## 常见问题

| 现象 | 检查与修正 |
| --- | --- |
| 同事打不开 | 主机是否登录/运行/睡眠；IPv4 是否正确；防火墙专用网络规则；客户端隔离/VPN |
| 端口放行检查 | 在主机回环地址网页顶部或托盘“检查与修复局域网访问”检查；缺少规则时点击修复并确认 UAC，随后用另一台电脑验证 |
| 修复仍受阻 | 查看页面列出的阻止规则/企业策略；自动修复不会删除阻止规则、关闭防火墙或修改路由器。跨网段客户端不属于自动放行的本地子网范围 |
| 无法锁定目录 | 同一目录已有实例，先从托盘退出；不要同时运行新旧版本 |
| 端口不可用 | 关闭占用程序，或退出后修改 `config.json` 的端口；同步同事访问地址 |
| PDF 上传或预览失败 | 损坏/密码/过大文件；运行兼容检测；更新系统与显卡驱动；用图片对比定位 |
| 打印超时/子进程异常 | 先查 Windows 打印队列及已出纸页数；不要直接重复提交 |
| 扫描仪不显示 | Windows WIA 服务和厂商 WIA 驱动；TWAIN-only 不支持；查看设备警告 |
| 纸张/双面不可选 | 当前驱动上报的能力不支持；用厂商完整驱动重新确认 |
| 自动启动不生效 | 当前用户是否登录；固定 EXE 路径；任务管理器启动应用/企业策略；超长路径 |
| 文件或任务不见了 | 浏览器 Cookie/隐私窗口不同；文件到期；任务记录满 24 小时清理 |
| state.json 损坏 | 退出后保留现场，恢复备份；不要用空状态文件覆盖以掩盖问题 |

删除程序前在托盘关闭自动启动并退出。按需备份/删除数据目录。默认日志不落盘；网页任务信息与兼容报告是首轮排查入口。没有自动下载更新、无人登录服务、多页扫描、TWAIN 或员工身份认证。
